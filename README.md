# Student Attendance Management System (C Mini Project)

## 📌 Project Description
This is a simple **Student Attendance Management System** developed using the **C programming language**.  
It uses **1D arrays**, **loops**, **conditional statements**, and **functions** to manage student attendance efficiently.

## 🛠 Tools & Technologies
- Programming Language: C
- Compiler: GCC
- Editor: VS Code

## ✨ Features
- Store attendance using 1D arrays
- Mark students as Present or Absent
- Display attendance records
- Count total present and absent students
- Menu-driven program

## 📚 Concepts Used
- Arrays
- Loops
- if-else conditions
- Functions
- Switch case
